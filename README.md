# Tavern Assets
Public CDN assets and character expression avatars for SillyTavern character cards.

## Revenge Heroes (破晓少年队)
Avatars location: `/avatars/revenge-heroes/`
Format: 256x256 Square WebP

### CDN URL Format:
- **jsDelivr (Global & CN High-Speed CDN)**:
  `https://testingcf.jsdelivr.net/gh/bpmstall/tavern-assets@main/avatars/revenge-heroes/{hero}_{expression}.webp`
- **GitHub Raw**:
  `https://raw.githubusercontent.com/bpmstall/tavern-assets/main/avatars/revenge-heroes/{hero}_{expression}.webp`
